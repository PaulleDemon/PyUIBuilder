# Quick start

## 1. Pick a framework

Open [pyuibuilder.com](https://pyuibuilder.com) and choose a target from the framework dropdown in the header:

- **Tkinter**
- **CustomTkinter**
- **PySide / PyQt**

Changing the framework later erases the canvas, so pick the one you want before you start building. See [Supported frameworks](supported-frameworks.md) for what each one is best for.

## 2. Build your UI

1. Every project needs one **Main window** widget — without it, code generation won't run.
2. Drag widgets from the **Widgets** tab onto the canvas.
3. Arrange them with **Flex**, **Grid**, or **Absolute** positioning (see [Layouts](layouts.md)).
4. Select a widget to open its attributes on the toolbar — colors, text, size, and more.
5. Need custom behavior on click/change/etc.? Use the **Code Editor** tab to write the event handler (see [Event handlers](event-handlers.md)).

## 3. Name your project

New projects are named `"untitled project"` by default. Rename it from the input next to the **Export code** button in the header.

## 4. Export or preview

- **Export code** (web and desktop) generates a Python file plus a `requirements.txt` if your UI uses any third-party widgets. See [Exporting code](exporting.md).
- **Preview** (desktop app only) runs your UI immediately, without exporting first. See [Desktop app](desktop-app.md).

## Example generated output

Here's what a small Tkinter UI (a label, a button, a map widget, and a time picker) generates:

```python
# This code is generated by PyUIbuilder: https://github.com/PaulleDemon/PyUIBuilder

import tkinter as tk
from tktimepicker import AnalogPicker, AnalogThemes, constants
import tkintermapview

main = tk.Tk()
main.config(bg="#332f2f")
main.title("Main Window")

timepicker = AnalogPicker(parent=main, type=constants.HOURS12)
timepicker_theme = AnalogThemes(timepicker)
timepicker_theme.setNavyBlue()
timepicker.place(x=80, y=145, width=250, height=350)

map_viewer = tkintermapview.TkinterMapView(master=main)
map_viewer.place(x=423, y=181, width=400, height=250)

label = tk.Label(master=main, text="Sample text")
label.config(bg="#E4E2E2", fg="#000")
label.place(x=83, y=69, width=130, height=46)

button = tk.Button(master=main, text="Click me")
button.config(bg="#65ff4a", fg="#0b0909")
button.place(x=457, y=108, width=80, height=40)

main.mainloop()
```

```bash
pip install -r requirements.txt
python your_generated_file.py
```

> Tkinter is OS-dependent — the same script can render slightly differently on Windows, macOS, and Linux. For a closer match between design and output, try the CustomTkinter or Pyside framework instead. See [FAQ](faq.md#common-faqs).
