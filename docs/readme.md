<br />

PyUIBuilder is a drag-and-drop GUI builder that generates real, editable **Python** code for **Tkinter**, **CustomTkinter**, and **PySide/PyQt**. 

You can use PyUIBuilder as a **web app**, or download the **desktop app**, which adds a live preview so you can run your UI without exporting first. See [Desktop app](desktop-app.md).

## Where to start

- New here? Start with [Quick start](getting-started.md).
- Want to know what's stable vs. in progress? See [Supported frameworks](supported-frameworks.md).
- Building something and stuck? Check the [FAQ](faq.md) first.
