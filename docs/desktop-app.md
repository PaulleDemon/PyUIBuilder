# Desktop app

Download the desktop app from [about.pyuibuilder.com/download](https://about.pyuibuilder.com/download/).

## Live preview

The desktop app has a **Preview** button that runs your current UI immediately, without exporting code first — useful for quickly checking how a design behaves before you commit to exporting.

## Python requirement

If the app detects your system doesn't already have Python installed, it will prompt you to install it so the exported code can run.

The desktop app ships with Python bundled in, **except on Mac Intel builds**, where it uses your system Python instead.

## Workspaces

A workspace is used to create a virtual environment for the app to run Python in — it does **not** automatically save your design. Use **Save/Load** (see [Exporting code](exporting.md#saving-and-loading-your-project)) to persist your actual project.
